# 法考同行 v2.0

三人法考学习工具：每日打卡、18 科 177 章讲义、1000 道原创题（50 套 × 20 题）、随堂练习、错题复习与个人笔记。

网页与 iPhone 入口：https://tangsan0530.github.io/my-first-repo/

Android APK：https://tangsan0530.github.io/my-first-repo/downloads/FakaoTongxing-v2.0.apk

iPhone 请用 Safari 打开网页，再选择“分享 → 添加到主屏幕”。Android APK 内置讲义与题库，登录与云同步需要网络。

成绩由服务端复算，支持多选精确匹配、UUID 去重、旧版 30 题兼容及题库版本隔离。三人互看竞赛成绩，章节笔记仅本人可见。

内容为学习草稿，尚未经过专业机构逐题审校，请结合现行法条及官方大纲学习。

每次 main 更新由 GitHub Actions 校验数据、运行同步回归、构建 APK，再一同发布网页和下载文件。Android 当前使用调试签名，跨构建覆盖安装可能出现签名冲突。
